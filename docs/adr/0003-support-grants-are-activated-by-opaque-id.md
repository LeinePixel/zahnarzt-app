# Supportfreigaben werden durch eine undurchsichtige ID aktiviert, nicht aufgelistet

**Status:** Accepted — 2026-08-29

Ein Praxisadmin erhält beim Anlegen einer Supportfreigabe deren technische, undurchsichtige Freigabe-ID und übermittelt sie im bestehenden Supportfall an den Anbieter. Ein Portaladmin kann nur genau diese ID mit einer strukturierten Ursache aktivieren; das Portal bietet keine Freigabeliste, Praxis-Suche oder Freitextsuche. Damit bleibt die Aktivierung bedienbar, ohne dass der Anbieter vor der Freigabe Praxen oder offene Supportfälle entdecken kann.
